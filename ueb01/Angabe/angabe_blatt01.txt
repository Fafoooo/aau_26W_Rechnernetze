                                         Übungsblatt 01
                      Python-Grundlagen für die Netzwerkprogrammierung



Ziel des Übungsblattes. In den folgenden Übungen werden die Python-Grundlagen erarbeitet, die im
weiteren Verlauf der Lehrveranstaltung für die Netzwerkprogrammierung benötigt werden. Der
Schwerpunkt liegt nicht auf dem Erlernen der gesamten Programmiersprache Python, sondern auf dem
sicheren Umgang mit Dateien, Zeichenketten und Bytes, binären Datenstrukturen sowie nebenläufigen
Programmen. Diese Konzepte werden in späteren Übungen direkt für die Implementierung von
Netzwerkprotokollen und Client-/Server-Anwendungen verwendet.

Programmiersprache. Verwenden Sie Python 3. Die Aufgaben sollen mit der Python-
Standardbibliothek gelöst werden; zusätzliche Pakete sind für dieses Übungsblatt nicht erforderlich.

Ü 1.2 Text, Zeichenketten und Bytes
Bei der Netzwerkprogrammierung werden Daten letztendlich als Folge von Bytes übertragen. Python
unterscheidet jedoch zwischen Zeichenketten (str) und Bytefolgen (bytes). Machen Sie sich mit
diesem Unterschied vertraut.
Erstellen Sie ein Programm, das eine Zeichenkette einliest und diese zunächst als UTF-8 in Bytes
kodiert. Geben Sie anschließend sowohl die Zeichenkette als auch die Bytefolge aus.
    text = "Hallo Netzwerk!"
    data = text.encode("utf-8")
    print(text)
    print(data)
    print(len(text))
    print(len(data))
Erweitern Sie das Programm, dass die Bytefolge wieder in eine Zeichenkette dekodiert wird.
Beantworten Sie folgende Fragen:
    Was ist der Unterschied zwischen str und bytes?
    Warum kann len(text) einen anderen Wert liefern als len(text.encode("utf-8"))?
    Was passiert, wenn eine Bytefolge mit der falschen Zeichenkodierung dekodiert wird?
    Warum ist die Unterscheidung zwischen Zeichenketten und Bytes für Netzwerkprogramme
       wichtig?

Ü 1.7 Producer-Consumer
Implementieren Sie abschließend das klassische Producer-Consumer-Problem. Ein Producer erzeugt
fortlaufend Integer-Werte und legt diese in einen gemeinsam genutzten Container. Ein oder mehrere
Consumer entnehmen Werte aus diesem Container und berechnen beispielsweise die Summe der
entnommenen Werte.
Anmerkung:
Das Producer-Consumer-Konzept trennt die Erzeugung von Daten oder Aufgaben von deren Verarbeitung. Producer
erzeugen Daten und legen sie in einer gemeinsamen Warteschlange (Queue) ab. Consumer entnehmen die Daten aus der
Queue und verarbeiten sie. Die Queue dient dabei als Puffer und ermöglicht es, dass Producer und Consumer unabhängig
voneinander mit unterschiedlicher Geschwindigkeit arbeiten können.
Verwenden Sie hierfür `queue.Queue` aus der Python-Standardbibliothek. Die Queue soll eine
begrenzte Größe besitzen, sodass der Producer gegebenenfalls warten muss, wenn der Container
voll ist.
Ihre Implementierung soll mindestens folgende Komponenten enthalten:
     einen Producer-Thread
     einen Consumer-Thread
     eine gemeinsam verwendete Queue
     eine Möglichkeit, das Ende der Produktion zu signalisieren
     eine Ausgabe der vom Consumer berechneten Ergebnisse
Beantworten Sie anschließend:
     Warum ist queue.Queue für diese Aufgabe geeigneter als eine normale Liste?
     Wie wird verhindert, dass der Consumer auf eine leere Queue zugreift?
     Wie wird verhindert, dass der Producer eine bereits volle Queue weiter befüllt?
     Wie kann der Consumer erkennen, dass der Producer keine weiteren Werte erzeugen wird?
